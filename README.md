# CVForge

A powerful, easy-to-use professional CV and resume builder. CVForge allows you to quickly enter your details, choose from multiple beautifully designed templates, preview your CV in real-time, and download it as a high-quality PDF.

## ✨ Features

- **Live Preview:** See your changes in real-time as you build your CV.
- **Multiple Professional Templates:** Choose from Professional, Modern, Classic Boxed, Premium, and Minimal themes.
- **Drag-and-Drop Reordering:** Easily rearrange your CV sections to suit your needs.
- **Customization:** Tweak the accent colors and font families for a personalized look.
- **Import/Export Data:** Save your progress as a JSON file and load it back anytime.
- **High-Quality PDF Generation:** Uses Puppeteer to render and export pixel-perfect PDFs.

## 🚀 Tech Stack

- **Frontend:** React, Vite, React Router, Lucide Icons
- **Backend:** Node.js, Express, Puppeteer (for PDF generation)

## 🛠️ Installation & Setup

To run this project locally, you will need to start both the backend server and the frontend client.

### 1. Start the Backend Server

```bash
cd server
npm install
npm start
```
The server will run on `http://localhost:5000`.

### 2. Start the Frontend Client

Open a new terminal window:
```bash
cd client
npm install
npm run dev
```
The client will be available on `http://localhost:5173`.
